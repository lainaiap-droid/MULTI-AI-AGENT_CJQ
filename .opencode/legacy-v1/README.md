# Legacy V1

Каталог содержит файлы, которые не используются в OpenCode V2.

## tools/

`confluence.ts` и `qase.ts` — реализация внешних инструментов через `.opencode/tools/*.ts` в формате OpenCode V1.

В OpenCode V2 файлы `.opencode/tools/*.ts` не регистрируются как инструменты и не появляются в каталоге инструментов. Рабочая замена — MCP-сервер `.opencode/mcp/qa-tools.mjs`.

Файлы сохранены только как историческая справка. Не подключай их и не изменяй в рамках текущего workflow.
