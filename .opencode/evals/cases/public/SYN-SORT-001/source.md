## Requirements Text

### 1. Общее описание

В списке задач исполнителя появилась возможность сортировки. Ранее список всегда выводился в порядке создания.

### 2. Требования

2.1. Список задач можно сортировать по трём полям: приоритет, срок выполнения и дата создания.

2.2. По умолчанию список отсортирован по дате создания от новых к старым.

2.3. При сортировке по приоритету задачи с высоким приоритетом идут раньше задач со средним, задачи со средним — раньше задач с низким.

2.4. При равенстве значений выбранного поля задачи упорядочиваются по дате создания, от новых к старым.

2.5. Направление сортировки переключается между возрастанием и убыванием отдельной кнопкой.

2.6. Выбранная сортировка сохраняется для пользователя между сессиями.

2.7. Сортировка применяется только к задачам, доступным пользователю; скрытые задачи не влияют на порядок видимых.

2.8. Если список пуст, отображается сообщение «Задач нет».

### 3. Ограничения

3.1. Сортировка по сроку выполнения: задачи без указанного срока всегда размещаются в конце списка, независимо от направления сортировки.

3.2. Перечень доступных для сортировки полей задаётся настройкой платформы и может быть расширен без изменения интерфейса.

### 4. Открытые вопросы

4.1. Не определено, как отображается индикатор активной сортировки при первом входе пользователя, который ранее сортировку не менял.

4.2. Не определено поведение при удалении поля из настройки платформы, если у пользователя сохранена сортировка по этому полю.
